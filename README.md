# 🚀 Full Stack Booking Appointment App

## 📖 Overview

A Full Stack Booking Appointment Application built using Node.js, Express.js, MySQL and Sequelize ORM following MVC Architecture.

### Features

* Add Users
* View All Users
* Delete Users
* MySQL Database Integration
* Sequelize ORM
* MVC Architecture
* Frontend Integration
* CORS Enabled
* JSON API Responses
